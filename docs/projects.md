# 开源项目

## Web 框架与基础库

| 项目 | 介绍 | 链接 |
| --- | --- | --- |
| tio-boot | 基于 Java AIO 和 t-io 的高性能 Web 框架。 | [文档](https://tio-boot.com/) · [GitHub](https://github.com/litongjava/tio-boot) |
| aio-socket | 异步非阻塞的 Java IO 库，通过内存页池复用缓冲区。代码出自 smart-socket。 | [GitHub](https://github.com/litongjava/aio-socket) |
| jfinal-aop | 从 JFinal 独立出来的 AOP 与依赖注入库，也是 tio-boot 的 Bean 容器。 | [文档](https://jfinal-aop.io.nexus/) · [GitHub](https://github.com/litongjava/jfinal-aop) |
| java-model | 各项目共用的注解、数据源信息和配置常量。 | [GitHub](https://github.com/litongjava/java-model) |
| hotswap-classloader | 基于 JVM 的动态类加载器，用于开发时热加载。 | [GitHub](https://github.com/litongjava/hotswap-classloader) |

## 数据库

| 项目 | 介绍 | 链接 |
| --- | --- | --- |
| java-db | 轻量的数据库操作框架，支持 MySQL、PostgreSQL、Oracle、SQLite 等，提供 ActiveRecord、Row、SQL 模板、事务和批量操作。 | [文档](https://java-db.io.nexus/) · [GitHub](https://github.com/litongjava/java-db) |
| api-table | 基于 java-db 的通用数据表操作工具，自动完成数据表与 JSON 的转换。 | [文档](https://api-table.io.nexus/) · [GitHub](https://github.com/litongjava/api-table) |

## AI

| 项目 | 介绍 | 链接 |
| --- | --- | --- |
| java-openai | 统一的 Java 大模型客户端，用同一套模型调用 OpenAI、Gemini、Claude、OpenRouter 等平台。 | [文档](https://java-openai.io.nexus/) · [GitHub](https://github.com/litongjava/java-openai) |
| DeepSeek Browser Use | 面向 AI 智能体的有状态浏览器服务，基于 Java 21、tio-boot 和 Playwright。 | [文档](https://deepseek-browser-use.io.nexus/) · [GitHub](https://github.com/litongjava/deepseek-browser-use) |
| telegram-bot-plus | 基于 TelegramBots 的 Java 机器人开发套件，提供发送限流、429 重试和按聊天顺序处理更新。 | [文档](https://telegram-bot.io.nexus/) · [GitHub](https://github.com/litongjava/telegram-bot-plus) |
| max-translator-bot | 基于 telegram-bot-plus 和 tio-boot 的中英翻译机器人。 | [文档](https://telegram-bot.io.nexus/telegram-bot-plus/02) · [GitHub](https://github.com/litongjava/max-translator-bot) |
| java-llm-proxy | 支持多模型的大语言模型代理服务。 | [GitHub](https://github.com/litongjava/java-llm-proxy) |
| whisper-cpp-server | 基于 OpenAI Whisper 的 C/C++ 实现的实时语音识别服务。 | [GitHub](https://github.com/litongjava/whisper-cpp-server) |
